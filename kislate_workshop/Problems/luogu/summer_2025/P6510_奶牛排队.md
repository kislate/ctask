# P6510 奶牛排队

## 题目描述

奶牛在熊大妈的带领下排成了一条直队。

显然，不同的奶牛身高不一定相同……

现在，奶牛们想知道，如果找出一些连续的奶牛，要求最左边的奶牛 $A$ 是最矮的，最右边的 $B$ 是最高的，且 $B$ 高于 $A$ 奶牛。中间如果存在奶牛，则身高不能和 $A,B$ 奶牛相同。问这样的奶牛最多会有多少头？

从左到右给出奶牛的身高，请告诉它们符合条件的最多的奶牛数（答案可能是 $0,2$，但不会是 $1$）。

## 输入格式

第一行一个正整数 $N$，表示奶牛的头数。

接下来 $N$ 行，每行一个正整数，从上到下表示从左到右奶牛的身高 $h_i$。

## 输出格式

一行一个整数，表示最多奶牛数。

## 输入输出样例 #1

### 输入 #1

```
5
1
2
3
4
1
```

### 输出 #1

```
4
```

## 说明/提示

#### 样例解释

取第 $1$ 头到第 $4$ 头奶牛，满足条件且为最多。

#### 数据范围

对于全部的数据，满足 $2 \le N \le 10^5$，$1 \le h_i <2^{31}$。

## 这道题得好好看看题:
**双单调栈**
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    stack<int> smax, smin;
    vector<int> heights(100005);
    int n, ans = 0;
    vector<int> max_barrier(100005, 0);
    vector<int> min_barrier(100005, 1e9);
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> heights[i];

    for (int i = 1; i <= n; i++) {
        while (!smin.empty() && heights[smin.top()] >= heights[i] ) {
            min_barrier[smin.top()] = i;
            smin.pop();
        }
        smin.push(i);
    }

    for (int i = n; i >= 1; i--) {
        while (!smax.empty() && heights[smax.top()] < heights[i]) {
            max_barrier[smax.top()] = i;
            smax.pop();
        }
        smax.push(i);
    }

    // for (int i = 1; i <= n; i++) cout << "max_barrier[" << i << "] = " << max_barrier[i] << endl;
    // for (int i = 1; i <= n; i++) cout << "min_barrier[" << i << "] = " << min_barrier[i] << endl;

    for (int i = n; i >= 1; i--) {
        // cout << "max_barrier[" << i << "] = " << max_barrier[i] << endl;
        for (int j = max_barrier[i] + 1; j < i; j++) {
            if (min_barrier[j] > i) ans = max(ans, i - j + 1);
        }
        if (i < ans) break; // beyond
    }

    cout << ans << endl;
    return 0;
}
```

## 下面这个是看最新一份的题解:
```cpp
#include <bits/stdc++.h>
using namespace std;

int main(void) {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, ans = 0;
    cin >> n;
    int tmax = 0, tmin = 0;
    vector<int> smax(n + 1, 0), smin(n + 1, 0), heights(n + 1, 0);
    for (int i = 1; i <= n; i++) cin >> heights[i];
    for (int i = 1; i <= n; i++) {
        while (tmin && heights[smin[tmin]] >= heights[i]) tmin--;
        while (tmax && heights[smax[tmax]] < heights[i]) tmax--;
        auto it = upper_bound(smin.begin() + 1, smin.begin() + tmin + 1, smax[tmax]); // smin是递增的. 找到第一个比他大的
        int index = it - smin.begin();
        if (index != tmin + 1) ans = max(ans, i - smin[index] + 1);
        // cout << "" << i << " " << index << " " << ans << endl;
        smax[++tmax] = i;
        smin[++tmin] = i;
    }
    cout << ans << endl;
    return 0;
}
```

## 差分满分做法:
```cpp
#include <bits/stdc++.h>
using namespace std;
int main(void) {
    int n, p;
    cin >> n >> p;
    vector<int> scores(n + 1, 0);
    vector<int> minus(n + 1, 0);
    cin >> scores[1];
    minus[0] = scores[1]; // 差分数组
    for (int i = 2; i <= n; i++) {
        cin >> scores[i];
        minus[i - 1] = scores[i] - scores[i - 1];
    }
    for (int i = 0; i < p; i++) {
        int l, r, d;
        cin >> l >> r >> d;
        minus[l - 1] += d;
        minus[r] -= d;
    }
    int min_ans = INT_MAX;
    scores[1] = minus[0];
    min_ans = min(min_ans, scores[1]);
    for (int i = 2; i <= n; i++) {
        scores[i] = scores[i - 1] + minus[i - 1];
        min_ans = min(min_ans, scores[i]);
    }
    cout << min_ans << endl;
    return 0;
}
```
